# Taskora

A responsive, single-page website built with plain **HTML, CSS and a little JavaScript** (no frameworks).

![Taskora preview](preview.png)

## Sections
Header and menu, Hero banner, About Us, Our Services, Pricing, FAQ, Contact Us, Sign Up and Footer.

## Run it
1. Download or clone this repository.
2. Open `index.html` in your browser. There is nothing to install.

## Files
| File | What it is |
|---|---|
| `index.html` | The page structure |
| `style.css` | All styles (mobile-first, breakpoints at 992px, 768px and 480px) |
| `script.js` | Mobile menu, FAQ, password check and demo form messages |
| `favicon.svg`, `logo.svg`, `logo-mark.svg`, `logo-preview.png` | Brand files |
| `logo.png`, `banner.png`, `about.png`, ... | Page images (all in the same folder) |
| `DESIGN_NOTES.md` | Colors, fonts, spacing and breakpoints |

## Notes
- The Contact and Sign Up forms are **demo only**. They show a message and do not send data anywhere. Connect a service such as Formspree before going live.
- Text, prices and the Facebook / Twitter / LinkedIn / Instagram links are placeholders to replace.

## Publish with GitHub Pages
Repository **Settings -> Pages -> Deploy from a branch -> `main` / root -> Save**. Your site will be live at `https://YOUR-USERNAME.github.io/YOUR-REPO/`.
